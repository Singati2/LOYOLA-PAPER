### A defect of the 19 October implementation, found while fixing R7

The guide linked the notebooks at the pinned code commit itself (`13a64e1`). The notebook files stored at that
commit still carried the previous pin (`549203c`), so a reviewer following a link would have run the older code
without the environment fix. The fix uses three commits: the code commit (the pin), a commit that only
regenerates the notebooks pinned to it, and a documentation commit whose links open the notebooks from the
second commit. The notebook badges now open the branch copy; the PIN inside the notebook, not the link,
determines the code that runs. `audit/test_review_2026_10_20.py` checks every link against the guide's commit.
