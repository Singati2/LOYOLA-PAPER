# Historical records

`v35/` holds the v35 audit logs, repair ledger, risk register, changelog and
diff exactly as they were at v35. They are superseded: counts and statements
in them (e.g. "39/39 references", provenance class totals, robustness counts)
refer to the v35 manuscript and dataset, not to the current version. For the
current state see `../README_V36.md` and `../V35_TO_V36_SCIENTIFIC_CHANGELOG.md`.
